1 Открыть PowerShell

Любой удобный способ:

  • Клавиша Win, введите PowerShell, откройте Windows PowerShell или Terminal.
  • В Проводнике зайдите в папку проекта → в адресной строке наберите powershell → Enter.
  • Или: Shift + ПКМ по пустому месту в папке → «Открыть окно PowerShell здесь».
Админ-права обычно не нужны, кроме установки Python через winget (иногда спрашивает подтверждение UAC).

2 Установить Python (если ещё нет)

Проверка

python --version
py --version
pip --version

Нужен Python 3.11+ (лучше 3.12). Если команда не найдена — ставим ниже.

Установка через winget (рекомендуется)

winget install Python.Python.3.12 --accept-package-agreements --accept-source-agreements

После установки закройте и снова откройте PowerShell, затем проверьте:

python --version
pip --version

Если winget недоступен

  1. Скачайте установщик: python.org/downloads
  2. Обязательно включите галочку Add python.exe to PATH
  3. Снова откройте PowerShell и проверьте версии
Если работает только py, а python — нет, дальше можно везде писать py вместо python (например: py -m venv venv).

3 Разрешить активацию venv в PowerShell

Без этого часто бывает ошибка про «выполнение сценариев отключено».

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

На вопрос подтверждения введите Y и нажмите Enter.

Достаточно сделать один раз на этом пользователе Windows.

4 Перейти в папку проекта

Папка должна содержать manage.py, requirements.txt, каталоги config и core.

# Подставьте свой путь:
Set-Location "C:\Users\Имя\Desktop\ROGA"

# Проверка, что вы в нужном месте:
Get-ChildItem manage.py, requirements.txt
Если путь с пробелами — кавычки обязательны. Пример: Set-Location "D:\Учёба\Проекты\ROGA"

5 Создать и активировать виртуальное окружение

python -m venv venv
.\venv\Scripts\Activate.ps1

В начале строки должно появиться (venv).

Проверка интерпретатора из venv:

Get-Command python | Format-List
python -c "import sys; print(sys.executable)"

Путь должен указывать внутрь папки ...\ROGA\venv\Scripts\python.exe.

6 Установить зависимости

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Будут установлены Django и Pillow. Проверка:

python -c "import django; print('Django', django.get_version())"

7 Миграции БД и суперпользователь

python manage.py migrate
python manage.py check

В корне проекта появится файл db.sqlite3.

Администратор для /admin/ (по желанию)

python manage.py createsuperuser
Логин: минимум 6 символов, только латинские буквы и цифры (без кириллицы и пробелов). Дальше PowerShell спросит email и пароль.

8 Запуск сервера

python manage.py runserver

Откройте в браузере:

http://127.0.0.1:8000/

Остановка: Ctrl + C.

Другой порт (если 8000 занят):

python manage.py runserver 8080

Доступ с других устройств в сети (осторожно, только для учёбы в локалке):

python manage.py runserver 0.0.0.0:8000

9 Весь скрипт первого запуска (скопировать в PowerShell)

Замените путь в первой строке на свой, затем вставьте блок целиком:

# === ROGA: первая установка через PowerShell ===

# 0) (один раз) разрешить Activate.ps1
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

# 1) перейти в папку проекта
Set-Location "C:\Users\Имя\Desktop\ROGA"

# 2) виртуальное окружение
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3) зависимости
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

# 4) база данных
python manage.py migrate
python manage.py check

# 5) админ (интерактивно: логин / email / пароль)
# python manage.py createsuperuser

# 6) сервер
python manage.py runserver
Строку с createsuperuser раскомментируйте, когда будете готовы ввести логин и пароль вручную. Пока сервер запущен, это окно PowerShell занято — так и должно быть.

10 Повторный запуск (каждый раз)

Set-Location "C:\Users\Имя\Desktop\ROGA"
.\venv\Scripts\Activate.ps1
python manage.py runserver

Выйти из venv:

deactivate

pip install и migrate снова нужны только если обновили зависимости или модели.

Частые ошибки в PowerShell

python / pip не найдены

winget install Python.Python.3.12 --accept-package-agreements --accept-source-agreements
# затем ЗАКРОЙТЕ и откройте PowerShell снова
py --version
py -m pip --version

ExecutionPolicy / «выполнение сценариев отключено»

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
.\venv\Scripts\Activate.ps1

No module named django

Не активирован venv. Снова:

.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

Порт занят

python manage.py runserver 8080

Проверить, что сервер слушает порт

Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort, State, OwningProcess
