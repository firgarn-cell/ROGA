1. Что это за проект

Веб-приложение на Django для регистрации пользователей и подачи заявок на обучение пассажиров городского транспорта.

  • Регистрация и вход
  • Личный кабинет с историей заявок
  • Создание заявки (вид транспорта, дата, оплата)
  • Админ-панель Django

База данных по умолчанию — SQLite (файл db.sqlite3 создаётся автоматически в папке проекта).

2. Что установить

  1. Python 3.11 или новее (лучше 3.12).
    Скачать: python.org/downloads
  2. При установке обязательно поставьте галочку «Add python.exe to PATH».
  3. После установки откройте Командную строку или PowerShell и проверьте: 
python --version
pip --version
Если команда python не найдена, попробуйте py --version и дальше везде заменяйте python на py.

3. Как найти папку проекта

Папка проекта — та, где лежат файлы:

  • manage.py
  • requirements.txt
  • папки config и core

Пример пути:

C:\Users\Имя\Desktop\ROGA

Или любой другой диск/каталог, куда вы скопировали проект.

Как открыть терминал сразу в этой папке

  1. Откройте папку в Проводнике Windows.
  2. Кликните по адресуной строке Проводника, введите cmd и нажмите Enter
    или в пустом месте папки: Shift + ПКМ → «Открыть окно PowerShell здесь».

Либо вручную:

cd /d C:\путь\к\вашей\папке\ROGA
Все команды ниже выполняйте из корня проекта (там, где лежит manage.py).

4. Запуск (пошагово)

Шаг 1. Создать виртуальное окружение

python -m venv venv

Появится папка venv — это изолированная установка Python для проекта.

Шаг 2. Активировать окружение

Командная строка (cmd):

venv\Scripts\activate.bat

PowerShell:

venv\Scripts\Activate.ps1
После активации в начале строки появится префикс (venv). Если PowerShell пишет про запрет скриптов, один раз выполните: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
затем снова venv\Scripts\Activate.ps1.

Шаг 3. Установить зависимости

pip install -r requirements.txt

Установятся Django и Pillow.

Шаг 4. Применить миграции (создать БД)

python manage.py migrate

В папке проекта появится файл db.sqlite3.

Шаг 5. Создать администратора (по желанию)

Нужен для входа в /admin/:

python manage.py createsuperuser
Логин должен быть не короче 6 символов и содержать только латинские буквы и цифры (без пробелов и кириллицы) — так устроена модель пользователя в проекте.

Шаг 6. Запустить сервер

python manage.py runserver

Откройте браузер и перейдите по адресу:

http://127.0.0.1:8000/

Остановка сервера: Ctrl + C в окне терминала.

5. Адреса страниц

Адрес Что открывается
http://127.0.0.1:8000/ Вход
http://127.0.0.1:8000/register/ Регистрация
http://127.0.0.1:8000/dashboard/ Личный кабинет
http://127.0.0.1:8000/apply/ Новая заявка
http://127.0.0.1:8000/admin/ Админ-панель
Страницы кабинета и заявки требуют входа. Сначала зарегистрируйтесь или войдите на главной (/, затем переходите в кабинет.

6. Повторный запуск (каждый следующий раз)

После первой настройки достаточно трёх действий:

cd /d C:\путь\к\вашей\папке\ROGA
venv\Scripts\activate.bat
python manage.py runserver

В PowerShell вместо activate.bat используйте Activate.ps1.

Миграции и pip install повторять не нужно, пока не меняли зависимости или модели.

7. Частые проблемы на Windows

«python не является внутренней или внешней командой»

  • Переустановите Python с галочкой Add to PATH.
  • Или используйте лаунчер: py -m venv venv, py manage.py runserver.

Ошибка политики выполнения в PowerShell

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Либо работайте через cmd и venv\Scripts\activate.bat.

«No module named django»

Окружение не активировано. Снова выполните активацию venv и проверьте, что в начале строки есть (venv).

Порт 8000 занят

python manage.py runserver 8080

Тогда сайт: http://127.0.0.1:8080/

Не создаётся суперпользователь / ошибка логина

Логин: минимум 6 символов, только a-z, A-Z, 0-9.

8. Чеклист быстрого старта

Все команды одним блоком (первый запуск, cmd)

cd /d C:\путь\к\вашей\папке\ROGA
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

Учебный проект ROGA («Пассажирам.РФ»). Файл можно открыть двойным щелчком в браузере — интернет для просмотра инструкции не нужен.
